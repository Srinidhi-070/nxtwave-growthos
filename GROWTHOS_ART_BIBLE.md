# GROWTHOS — FULL VISUAL REVAMP MASTER PROMPT

This document serves as the foundational Art Bible and Product UX directive for the GrowthOS application.

## CORE CREATIVE DIRECTION
GrowthOS is a COMPLETE DIGITAL WORLD, not a traditional SaaS website. It uses a futuristic pixel-art city / retro game visual language.

**Color Palette:**
- Base: Deep Indigo, Purple, Deep Navy (70-80%)
- Lighting: Cyan, Teal (15-20%)
- Accents: Magenta, Pink, Lime Green (5-10% for interactive/achievements)

## THE UI IS INSIDE THE WORLD
The interface must feel integrated into an environment (e.g., Dashboard inside a digital room, Quest page over a pixel campus map).

## BACKGROUND SYSTEM (PixelEnvironment)
Backgrounds are not static. We use a reusable animated pixel environment system with multiple layers:
1. Sky
2. Clouds
3. Distant buildings
4. Midground architecture
5. Foreground structures
6. Lighting
7. Particles

## DYNAMIC WORLD STATE (Crucial)
The world reacts to progress:
- **New student:** Dark quiet city. One little AI terminal glowing.
- **Character created:** A nearby building lights up.
- **First referral:** A signal travels through the environment.
- **3 crew members:** More windows turn on.
- **Workshop live:** Transit lights activate.
- **Project started:** Their lab turns on.
- **Project shipped:** Character stands in front of a fully illuminated AI lab.

## ADMIN EXPERIENCE
The Admin console is an "Operator Terminal" *inside* this same pixel world. It uses the same deep indigo base and teal/cyan signal lines, but with high information density (like a telemetry observatory).

## AUDIO SYSTEM
Ambient night city noise, UI hover ticks, and game achievement sounds. (Requires explicit "Enable Audio" user interaction).

## PHASED IMPLEMENTATION
This will be implemented in a phased approach, starting with the `<PixelEnvironment>` rendering system and global motion system.
